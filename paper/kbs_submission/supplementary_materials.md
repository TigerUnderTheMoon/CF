# Supplementary Material Descriptions

**Supplementary Figure S1**: Governance diagnostic upset plot showing per-key marginal exclusion contributions and audit-limited intersection patterns for the six non-overlap keys used in the Real-Task v3 manifest gate. The `non_empty_alias_hash` key exhibits total collapse for GSM8K because all 7,473 affected rows share the identical SHA-256 hash of the empty string (`e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`). Generated from `outputs/real_task_v3/governance_diagnostic_upset.png` and packaged as `paper/kbs_submission/supplementary/Supplementary_Figure_S1_governance_diagnostic_upset.png`. Resolution: 300 DPI PNG; current color mode: RGBA.

**Supplementary Data S1**: Structured governance diagnostic report in JSON format. Contains findings F1 (empty-alias hash collision), F2 (split consumption), and F3 (six-key OR exclusion), with severity labels, per-key marginal contributions, and future-work recommendations. Generated from `outputs/real_task_v3/governance_diagnostic_report.json` and packaged as `paper/kbs_submission/supplementary/Supplementary_Data_S1_governance_diagnostic_report.json`. Schema: see report root keys `status`, `diagnostic_findings`, and `recommendations_for_future_work`.

**Supplementary Note S1**: Claim-safe audit trail. Provides frozen audit artifact paths and statuses for the real-task routes: v2.1 failed full validation (`outputs/s_fma_v2_1_fresh_holdout/v2_1_full_validation_failure_audit.json`), v2.1 abandonment (`outputs/s_fma_v2_1_fresh_holdout/v2_1_full_validation_abandonment_audit.json`), v3 source preparation (`outputs/real_task_v3/source_preparation_failure_audit.json` and `outputs/real_task_v3/source_preparation_success_audit.json`), v3 manifest blockage (`outputs/real_task_v3/manifest_overlap_audit.json` with `BLOCKED_OVERLAP_DETECTED`), and final status (`outputs/real_task_v3/real_task_v3_final_status.json` with `REAL_TASK_V3_DATA_SCARCITY_BLOCKED`). No API calls, smoke runs, replay, scoring, or downstream evaluations were executed after manifest blockage.
